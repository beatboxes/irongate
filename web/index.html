🛡️ Protection Settings

                
                

                
                
                

                    
Protection Status

                    

                        

                            

                            Disabled
                        

                        

                    

                    

                        When enabled, Irongate enforces zone-based network isolation for all devices in the Devices & Zones list.
                    

                

                
                
                

                    
Isolation Mode

                    

                        

                            
🔧 Single-NIC Mode

                            

                                Software-based isolation

                                No hardware changes needed

                                ~99% effective
                            

                        

                        

                            
🔒 Dual-NIC Mode

                            

                                Hardware bridge isolation

                                Requires USB NIC (~$10)

                                100% effective (VLAN-equivalent)
                            

                        

                    

                

                
                
                

                    
Dual-NIC Bridge Configuration

                    

                        
                        
                        

                            Connect USB ethernet adapter. Protected servers connect to a switch on this interface.
                        

                    

                    

                        

                        

                        

                    

                    

                        Required Topology:

                        
[Router] ─── [Main Switch] ─── [eth0] ─── [IRONGATE] ─── [eth1/USB] ─── [Isolated Switch]
                                                                              │   │   │
                                                                            [Srv1][Srv2][Srv3]

                    

                

                
                
                

                    
Protection Layers (Single-NIC Mode)

                    

                        
                        
                        
                        
                        
                    

                    

                        ⛓️ Layer 8 Blockchain - Configure on the Layer 8 Blockchain page for 100% VLAN-equivalent protection.
                    

                

                
                
                

                    
                    
                    
                

                
                
                

                    
How Irongate Protection Works

                    

                        

                            Single-NIC Mode (7-Layer):
                            
    
                                
  1. ARP defense against spoofing attacks
    2. 
                                
  2. IPv6 RA to capture IPv6 devices
    3. 
                                
  3. nftables zone-based firewall rules
    4. 
                                
  4. Gateway takeover intercepts traffic
    5. 
                                
  5. Active monitoring detects evasion
    6. 
                                
  6. Device ARP spoofing claims protected IPs
    7. 
                                
  7. ARP reply interception prevents L2 bypass
    8. 
                            

                        

                        

                            Dual-NIC Mode:
                            
    
                                
  • Linux bridge with port isolation
    • 
                                
  • Kernel-enforced - impossible to bypass
    • 
                                
  • Same security as managed switch VLANs
    • 
                                
  • Separate DHCP pool for isolated network
    • 
                                
  • NAT provides internet access
    • 
                            

                        

                    

                

            

            
            
            

                
⛓️ Layer 8: Algorand Blockchain

                
                

                
                
                

                    
What is Layer 8?

                    
Layer 8 adds cryptographic device verification via the Algorand blockchain. Each device must be registered on-chain to access protected resources.

                    

                        

                            🔐 Immutable Registry
                            
Device list stored on blockchain - tamper-proof

                        

                        

                            🛡️ MAC Spoof Protection
                            
Cryptographic proof defeats spoofing attacks

                        

                        

                            📜 Audit Trail
                            
Every access attempt logged permanently

                        

                        

                            💰 Low Cost
                            
~$0.50/month for 100 devices

                        

                    

                

                
                
                

                    
Blockchain Status

                    

                        

                            

                            Disabled
                        

                        

                    

                    

                        When enabled, devices must be registered on the Algorand blockchain to access protected resources.
                        Requires a deployed smart contract (App ID).
                    

                

                
                
                

                    
Smart Contract Configuration

                    

                        

                            
                            
                        

                        

                            
                            
                            

                                Deploy with: python3 /opt/irongate/smart_contract.py
                            

                        

                    

                    

                        
                        
                        

                            ⚠️ Keep secure! Only needed for registering/revoking devices.
                            
                        

                    

                

                
                
                

                    
Behavior Settings

                    

                        
                        
                        
                    

                    

                        
                        
                        

                            How long to cache device verification. Higher = fewer blockchain queries, lower = faster revocation.
                        

                    

                

                
                
                

                    
                    
                    
                

                
                
                

                    
Command Line Tools

                    

                        
irongate-blockchain status - Show connection status

                        
irongate-blockchain list - List registered devices

                        
irongate-blockchain register - Register a new device

                        
irongate-blockchain revoke <mac> - Revoke a device

                        
irongate-blockchain verify <mac> <ip> - Test verification

                        
irongate-blockchain sync - Sync devices from config to blockchain

                    

                

                
                
                

                    
Setup Guide

                    
    
                        
  1. Install Algorand SDK: pip install py-algorand-sdk --break-system-packages
    2. 
                        
  2. Compile smart contract: python3 /opt/irongate/smart_contract.py
    3. 
                        
  3. Create Algorand wallet (Pera Wallet or MyAlgo) and fund with ~1 ALGO
    4. 
                        
  4. Deploy contract using AlgoKit or goal CLI
    5. 
                        
  5. Enter App ID and mnemonic above
    6. 
                        
  6. Enable blockchain and save
    7. 
                        
  7. Register devices: irongate-blockchain sync
    8.
